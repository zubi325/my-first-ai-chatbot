
# My First AI Chatbot

My first Python chatbot project, created using Visual Studio Code.

## Features
- Greets users
- Answers simple questions
- Responds to help requests
- Runs in the terminal

## Technologies Used
- Python
- Visual Studio Code

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python chatbot.py
```
